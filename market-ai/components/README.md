# 🧩 Components Directory

Shared React components used across the application.

## Components

| Component | Purpose |
|-----------|---------|
| `AuthStatus.tsx` | Display auth state |
| `ComplianceBadge.tsx` | Compliance indicators |
| `IntegrationsPanel.tsx` | Integration settings |
| `KycPanel.tsx` | KYC verification UI |
| `ModerationQueue.tsx` | Content moderation |
| `NotificationBell.tsx` | Notification indicator |
| `OpsActions.tsx` | Operations panel |
| `Providers.tsx` | Context providers |

## Conventions
- Use PascalCase for component files
- Export default the main component
- Include PropTypes or TypeScript interfaces
- Keep components focused and small
